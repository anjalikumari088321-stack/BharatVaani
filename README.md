# BharatVaani - Gaon Ka AI Dost

AI for Bharat - Built at Build AI Hackathon 2026

## Live Demo
https://bharatvaani-a5fw.onrender.com

## Problem
Gaon ke kisano ko Hindi/Braj Bhasha me kheti ki jankari nahi milti.

## Solution
Voice based AI assistant jo Braj Bhasha samajhta hai aur bolta hai.

## Tech Stack
- Frontend: React.js
- Backend: Node.js
- AI: Google Gemini 2.0 Flash
- Voice: Sarvam AI
- Deployed on: Render
